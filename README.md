# 🟡 Pac-Man Adventure

一款使用 **HTML、CSS、JavaScript** 製作的 Pac-Man 遊戲。

本專案除了完成職訓局課程作業外，也將以作品集(Project Portfolio)的標準進行開發。

---

## 📖 專案介紹

Pac-Man Adventure 是一款經典吃豆人遊戲。

玩家需要控制 Pac-Man 收集所有豆子，同時避開鬼魂追擊，成功完成所有關卡即可獲得勝利。

本專案預計完成 10 個關卡，並加入更多有趣的遊戲元素。

---

## 🎯 遊戲特色

- 🎮 共 10 個關卡
- ❤️ 三條生命
- 👻 多種鬼魂 AI
- ⚡ Power Pellet（大力丸）
- 🍎 水果加分
- 🚪 傳送門
- 🏆 分數系統
- 💾 LocalStorage 紀錄最高分
- 🎉 完成遊戲可觀看獎勵影片（Rick Roll）

---
