# Pac-Man Adventure Game Design

本文件整理 Pac-Man Adventure 的遊戲需求與功能規劃。

目前專案會先以 **HTML 與 CSS 畫面製作** 為主，之後再逐步加入 JavaScript，讓遊戲可以互動與執行規則。

---

## 1. 專案目標

Pac-Man Adventure 是一款參考經典 Pac-Man 玩法製作的網頁遊戲。

玩家需要控制 Pac-Man 在迷宮中移動，收集豆子、避開鬼魂，並完成所有關卡。專案目標除了完成課程作業，也希望整理成適合作品集展示的作品。

| 目標 | 說明 |
| --- | --- |
| 課程作業 | 使用 HTML、CSS、JavaScript 完成一款可遊玩的網頁遊戲 |
| 學習練習 | 先用 HTML 和 CSS 建立畫面，再逐步理解 JavaScript 的互動邏輯 |
| 作品集 | 保持檔案結構清楚、文件完整，方便未來展示與回頭維護 |

---

## 2. 基本遊戲玩法

玩家操作 Pac-Man 在迷宮中移動，主要目標是吃完關卡中的所有豆子。

遊戲過程中會出現鬼魂，玩家需要避開鬼魂。如果 Pac-Man 撞到鬼魂，會扣除一條生命。當所有豆子都被吃完時，玩家通過目前關卡並進入下一關。

| 遊戲元素 | 說明 |
| --- | --- |
| Pac-Man | 玩家控制的角色 |
| 迷宮 | 玩家與鬼魂移動的遊戲區域 |
| 豆子 | 主要收集目標，吃完所有豆子即可過關 |
| 鬼魂 | 會在迷宮中移動並威脅玩家 |
| 分數 | 玩家吃豆子、水果、鬼魂或過關時增加 |

---

## 3. 操作方式

玩家可以使用鍵盤控制 Pac-Man 的移動方向。

| 操作 | 按鍵 |
| --- | --- |
| 向上移動 | 方向鍵 Up 或 W |
| 向下移動 | 方向鍵 Down 或 S |
| 向左移動 | 方向鍵 Left 或 A |
| 向右移動 | 方向鍵 Right 或 D |

---

## 4. 生命與失敗條件

玩家一開始有 **三條生命**。

當 Pac-Man 撞到鬼魂時，會扣除一條生命。如果生命歸零，遊戲結束並顯示 **Game Over** 畫面。

| 狀態 | 結果 |
| --- | --- |
| 撞到鬼魂 | 扣除 1 條生命 |
| 生命還沒歸零 | 玩家可以繼續遊戲 |
| 生命歸零 | 顯示 Game Over |

---

## 5. 關卡設計

遊戲預計共有 **10 個關卡**。

關卡難度會由簡單逐步提高，讓玩家可以先熟悉操作，再面對更具挑戰性的迷宮與鬼魂行為。

| 關卡範圍 | 難度方向 |
| --- | --- |
| 第 1 關 | 基礎迷宮，讓玩家熟悉移動與吃豆子 |
| 第 2 到 5 關 | 逐步增加難度，例如路線更複雜或鬼魂壓力提高 |
| 第 6 到 9 關 | 挑戰性更高，需要更注意鬼魂與路線選擇 |
| 第 10 關 | 最終關卡，完成後進入 Victory 畫面 |

完成第 10 關後，遊戲會顯示 **Victory**，並提供 Rick Roll 獎勵影片。

---

## 6. 遊戲物件

遊戲中會出現豆子、水果、大力丸與傳送門。

| 物件 | 功能 |
| --- | --- |
| 豆子 | Pac-Man 的主要收集目標 |
| 水果 | 額外加分物件 |
| 大力丸 | 讓鬼魂進入害怕狀態，玩家可以吃掉鬼魂 |
| 傳送門 | 讓 Pac-Man 從迷宮一側移動到另一側 |

---

## 7. 鬼魂狀態

鬼魂會有不同狀態，讓遊戲更有變化。

| 狀態 | 說明 |
| --- | --- |
| 巡邏 | 鬼魂依照路線在迷宮中移動 |
| 追擊 | 鬼魂朝 Pac-Man 的方向移動，增加壓力 |
| 害怕 | Pac-Man 吃到大力丸後，鬼魂暫時變成可以被吃掉的狀態 |

---

## 8. 分數規則

玩家在遊戲中會依照不同事件獲得分數。

| 事件 | 分數 |
| --- | ---: |
| 吃到豆子 | +10 |
| 吃到水果 | +100 |
| 吃到鬼魂 | +200 |
| 完成關卡 | +1000 |

---

## 9. HUD 顯示

遊戲主畫面上方會顯示 HUD，讓玩家可以隨時知道目前狀態。

| HUD 項目 | 說明 |
| --- | --- |
| Score | 顯示目前分數 |
| Lives | 顯示剩餘生命 |
| Level | 顯示目前關卡 |

---

## 10. 遊戲畫面流程

| 畫面 | 說明 |
| --- | --- |
| 開始畫面 | 顯示遊戲標題、Pac-Man 圖示、Start Game 按鈕與操作提示 |
| 遊戲主畫面 | 顯示 HUD、迷宮、豆子、Pac-Man、鬼魂等內容 |
| 暫停畫面 | 顯示暫停狀態，提供繼續遊戲與重新開始 |
| 過關畫面 | 顯示 Level Clear 與目前分數，提供下一關按鈕 |
| Game Over 畫面 | 生命歸零時顯示，提供重新挑戰與回到首頁 |
| Victory 畫面 | 完成第 10 關後顯示，提供 Rick Roll 獎勵影片 |

---

## 11. 作業基本版本 MVP

MVP 是最小可完成版本，代表先把作業需要的基本遊戲流程做出來。

| 功能 | 說明 |
| --- | --- |
| 開始畫面 | 顯示遊戲標題、Pac-Man 圖示與開始按鈕 |
| 遊戲主畫面 | 顯示 HUD 與迷宮 |
| 玩家移動 | 使用方向鍵或 WASD 控制 Pac-Man |
| 豆子收集 | Pac-Man 吃豆子並增加分數 |
| 鬼魂與碰撞 | 至少加入一隻鬼魂，碰到玩家時扣除一條生命 |
| 生命系統 | 玩家初始有三條生命 |
| Game Over | 生命歸零時顯示結束畫面 |
| 10 關系統 | 完成目前關卡後進入下一關，總共有 10 關 |
| Victory | 完成第 10 關後顯示勝利畫面 |
| 過關獎勵 | 完成第 10 關後提供 Rick Roll 獎勵影片 |

---

## 12. 未來作品集擴充功能

以下功能適合在基本版本完成後，再作為作品集強化內容。

| 功能 | 說明 |
| --- | --- |
| 多種鬼魂 AI | 讓不同鬼魂有不同巡邏與追擊方式 |
| 大力丸效果 | 讓鬼魂進入害怕狀態，玩家可以吃鬼加分 |
| 水果加分 | 在迷宮中加入水果，提供額外分數 |
| 傳送門 | 讓迷宮左右或指定位置可以互相傳送 |
| LocalStorage 最高分 | 在瀏覽器中保存最高分紀錄 |
| Rick Roll 獎勵影片 | 完成所有關卡後提供獎勵影片 |
