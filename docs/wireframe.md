# Pac-Man Adventure Wireframe

Wireframe 是遊戲畫面的初步配置圖。

目前只規劃畫面中的內容與位置，暫時不處理顏色、動畫及 JavaScript 功能。

---

## 1. 開始畫面

```text
┌──────────────────────────────────────────┐
│                                          │
│            PAC-MAN ADVENTURE             │
│                                          │
│                  🟡                      │
│                                          │
│              [ START GAME ]              │
│                                          │
│            使用方向鍵或 WASD             │
│                                          │
└──────────────────────────────────────────┘
```

### 畫面內容

- 遊戲標題
- Pac-Man 圖示
- 開始遊戲按鈕
- 操作方式提示

## 響應式畫面規劃

### 桌機版

- 遊戲區置中顯示
- HUD 橫向排列
- 保留完整迷宮比例

### 手機版

- 遊戲區依螢幕寬度縮放
- HUD 保持精簡
- 加入畫面上的方向控制按鈕
